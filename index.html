Movies needs a TMDB API key

Movies are powered by TMDB, a free movie database.

  1. Create a free TMDB account and grab your v3 API key from TMDB settings → API.
  2. Open movies.js in this folder and paste it on the line:
    const API_KEY = "YOUR_TMDB_V3_API_KEY";
  3. Reload the page — that's it.

On a static site like this the key is publicly visible in movies.js. That is expected and allowed by TMDB for browser apps — but never put your private API Read Access Token (the long bearer token) in any frontend file.
